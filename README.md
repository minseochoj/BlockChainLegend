# BlockChainLegend

A simple BlockChainLegend Manager for Real time Data Processing.

BlockChainLegend is built to be simple and practical, focusing on doing one thing well.

**Why BlockChainLegend?**

- A simple BlockChainLegend Manager for
- Real time Data Processing

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockChainLegend.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

BlockChainLegend is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
